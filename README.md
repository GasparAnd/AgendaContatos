📱 Agenda de Contatos

Projeto didático desenvolvido em Java na disciplina de Programação Orientada a Objetos (POO). Seu objetivo é praticar conceitos fundamentais de programação e acompanhar a evolução da organização, estruturação e persistência de dados.

O projeto evolui de uma aplicação procedural simples para uma estrutura modular, incorporando gradualmente coleções, métodos, persistência em arquivos, classes e objetos.

📌 Versão atual

V.3.1.0 — Manipulação de Objetos com List e ArrayList

Nesta versão, o projeto avança na introdução à Programação Orientada a Objetos, utilizando a classe Contato para criar objetos que representam pessoas cadastradas na agenda.

Os objetos são armazenados em uma coleção List<Contato>, permitindo reunir os dados de cada contato em uma única estrutura.

Principais novidades
Criação de vários objetos da classe Contato;
Armazenamento dos objetos em uma lista ArrayList<Contato>;
Adição de objetos à lista utilizando add();
Percorrimento da lista utilizando for-each;
Percorrimento da lista utilizando for tradicional;
Acesso aos objetos por índice utilizando get();
Acesso aos atributos dos objetos;
Utilização de contatos.get(0).nome para acessar diretamente um atributo de um objeto armazenado na lista.

Importante: nesta versão, os exemplos com objetos Contato são executados separadamente das funcionalidades da agenda. O CRUD e a persistência ainda utilizam as listas paralelas de String das versões anteriores.

🎯 Objetivo

Construir uma Agenda de Contatos completa, evoluindo gradualmente dos fundamentos da programação procedural para a Programação Orientada a Objetos, com organização em classes, manipulação de objetos e persistência de dados.
